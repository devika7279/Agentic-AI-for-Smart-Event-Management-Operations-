Agentic AI for Smart Event Management Operations.

EventOps AI is a fullfeatured, agentpowered event management system designed to streamline the
planning, execution, and monitoring of largescale events (conferences, hackathons, exhibitions,
corporate summits). The platform replaces fragmented manual processes with intelligent
automation, realtime analytics, and rolebased dashboards for both attendees and administrators.

�� Core Value Proposition
• Reduce operational overhead by automating registration, venue management, speaker
coordination, sponsorship tracking, and incident handling.
• Enhance attendee experience through selfservice registration, checkin, and realtime
notifications.
• Empower organisers with centralised visibility, predictive insights (health scores, bottleneck
detection), and actionable recommendations.
• Enable autonomous decisionmaking via specialised AI agents that collaborate and adapt to
event dynamics.

�� Intelligent Agents (AI Modules)
The platform implements five core agents, each responsible for a specific domain:
1. Registration Agent – Processes attendee signups, validates data, generates tickets, tracks
checkins, and provides attendance analytics.
2. Venue Agent – Manages room availability, seating optimisation, resource utilisation, and
generates capacity reports.
3. Speaker Agent – Schedules speaker sessions, tracks availability, detects overlaps, and
recommends agenda adjustments.
4. Sponsorship Agent – Monitors sponsor deliverables, calculates ROI, tracks visibility metrics,
and manages sponsor workflows.
5. Incident Agent – Captures operational issues, prioritises by severity, coordinates responses,
and escalates critical incidents automatically.
A central Event Intelligence Engine aggregates data from all agents, computes a realtime Event
Health Score, predicts bottlenecks, and suggests optimisation actions. It also orchestrates agent
activities to ensure cohesive operation.

�� User Roles &amp; Dashboards
• Landing Page – Marketingoriented overview with feature highlights, howitworks,
testimonials, and calltoaction.

• User Dashboard – Attendees can browse upcoming events, register with ticket selection,
view their registrations, and selfcheckin via a simple button.
• Admin Dashboard – Comprehensive control panel with dedicated tabs:
o Overview – KPI cards (health score, registrations, incidents, etc.) and quick
summaries.
o Registrations – List all attendees, add new registrations, and perform checkins.
o Venue – Visualise room occupancy and utilisation.
o Speakers – Manage speaker profiles and assign sessions.
o Sponsors – Track sponsors, ROI, and deliverables.
o Incidents – Report and resolve issues with severity tagging.
o Intelligence Engine – Detailed agent performance charts, health trends, and
agentlevel metrics (including a modal for deep dives).
o Notifications – Send email/SMS/push alerts and view notification history.
